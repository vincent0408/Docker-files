# Docker-files

Saved Docker images and AI models, stored with Git LFS (`git lfs install` before cloning).

- `open-webui/`, `open-terminal/`: Docker image archives
- `models/`: Qwen3 embedding and reranker models (Q8_0 GGUF) for llama.cpp `llama-server`, e.g. on Windows with CUDA; see `models/README.md`
